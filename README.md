# Cookery Engineering

Cookery Engineering is an industrial food-processing add-on for Immersive Engineering and Kaleidoscope Cookery, built for Minecraft 1.21.1 with NeoForge.

## Added Content

- **Industrial Maturation Vessel** — Automates Kaleidoscope Cookery Stockpot recipes using an electrically powered multiblock batch process.
- **Large Thresher** — Processes Kaleidoscope Cookery Millstone recipes with high-throughput item input and automatic output.

## Garden Cloche Compatibility

- Adds Garden Cloche recipes for crops from selected mods in the Kaleidoscope series.
- Adds support for Farmer's Delight Rich Soil and crops from selected add-ons. Compatibility for the Farmer's Delight base mod is not currently planned because it is already covered by an existing compatibility mod.

## Future Development Plans

- An industrial machine for roasting meat.
- A cultivation and processing workflow for a certain high-protein animal.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.252 or newer
- Immersive Engineering 12.4.2 or newer
- Kaleidoscope Cookery 1.5.0 or newer
- Java 21

## Building

The development environment uses ModDevGradle 2.0.147 and Gradle 9.2.1. On Windows, run:

```powershell
.\gradlew.bat build
```

The built mod JAR is written to `build/libs/`.

# 烹饪工程

烹饪工程是一个面向 Minecraft 1.21.1、基于 NeoForge 的 Immersive Engineering 与 Kaleidoscope Cookery 工业食品加工附属模组。

## 加入内容

- **工业熟化釜**——以电力驱动的多方块批次工序自动处理 Kaleidoscope Cookery 汤锅配方。
- **大型脱粒机**——以高通量投料和自动输出处理 Kaleidoscope Cookery 石磨配方。

## 园艺玻璃罩兼容

- 为 Kaleidoscope 系列部分模组的作物添加园艺玻璃罩配方。
- 兼容农夫乐事沃土及部分附属模组的作物。农夫乐事本体已有其他兼容模组覆盖，因此目前不另行开发。

## 后续开发计划

- 用于烤肉的工业设备。
- 某种高蛋白动物的培育及处理流程。

## 运行要求

- Minecraft 1.21.1
- NeoForge 21.1.252 或更高版本
- Immersive Engineering 12.4.2 或更高版本
- Kaleidoscope Cookery 1.5.0 或更高版本
- Java 21

## 构建

开发环境采用 ModDevGradle 2.0.147 与 Gradle 9.2.1。在 Windows 下执行：

```powershell
.\gradlew.bat build
```

构建完成的模组 JAR 位于 `build/libs/`。
